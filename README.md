# 簿記ことば

日商簿記2級・3級の勘定科目を、単語カードと毎日のクイズで覚える学習アプリです。

**[アプリを開く（スマホ・PC）](https://satokott4274-blip.github.io/boki-kotoba/)**

インストール・ログインは不要です。上のリンクをスマホのブラウザで開いて使えます。

## できること

- 243語の単語カードで、名前・意味・分類・借方／貸方を確認
- 「今日の10問」で分類・借貸・取引の問題を練習
- 72問の取引四択と10組の使い分けを学習
- 3級・2級・工業簿記の切り替え、検索、苦手な語の復習
- 学習記録の自動保存と途中再開

参考用の10語はクイズから除外しています。2級の設定には3級の基礎も含みます。

## 手元で開く

Python 3がある場合、このフォルダで次を実行し、表示されたローカルURLをブラウザで開きます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

[ローカルのアプリを開く](http://127.0.0.1:8000/)

パッケージのインストールは不要です。`index.html` はCSSとJavaScriptを含む単体ファイルです。

## 編集とビルド

編集対象は `dist/` 内のファイルです。編集後、以下でルートの `index.html` を更新します。

```sh
python3 build_standalone.py
```

出力先を指定する場合は `python3 build_standalone.py --output path/to/app.html` を使用します。

| ファイル | 内容 |
| --- | --- |
| `dist/index.html` | HTMLの土台 |
| `dist/styles.css` | PC・スマホの表示 |
| `dist/data.js` | 教材データ |
| `dist/core.js` | 出題・復習・記録のロジック |
| `dist/app.js` | 画面と操作 |
| `index.html` | ビルド済みの単体アプリ |

## GitHub Pages

GitHub Pagesの「Deploy from a branch」、ブランチ `main`、フォルダ `/(root)` から公開しています。`dist/` を編集した後はビルドして `index.html` もコミット・pushすると、公開アプリに反映されます。アプリとソースコードは一般公開です。

スマホでは下部ナビゲーションと1列の問題表示になります。級切り替え・詳細表示などのボタンは44px以上の高さを確保し、画面端の安全領域に対応しています。次の単語へ進むとカードの先頭が表示されます。

## 学習記録について

学習記録は利用したブラウザ内のlocalStorageに保存します。サーバーへの送信、ログイン、クラウド同期はありません。端末・ブラウザ・URLが変わると記録は引き継がれません。ブラウザのサイトデータを消すと記録も消えます。

## 教材

日本商工会議所の出題区分表・標準的な勘定科目を参照した自主制作の学習用教材です。各語の説明・例題は学習用に作成しています。日商公式アプリではありません。教材の参照先と対象範囲は、アプリ内「このアプリについて」に記載しています。試験では問題文で指定された勘定科目を優先してください。

## 動作確認

基礎機能はPC幅1280px、スマホ幅390px・320pxで主要操作を確認済みです。10問の回答、誤答の復習登録、途中再開、複数タブの保存競合、検索、級切り替えを検証しました。公開前のスマホ向け追加調整はコードレビューとJavaScript構文・ビルド検証を実施しました。物理スマートフォンとSafariでの実機操作は未確認です。
